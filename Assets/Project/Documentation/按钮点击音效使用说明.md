# 按钮点击音效使用说明

本项目所有可点击 UI 统一使用 `button-dry.mp3` 作为点击音效，**新按钮无需任何手动配置**即自动发声。

角色走路 / 跑步的脚步声也已接入（基于动画事件），见文末「七、角色脚步声」。

## 一、效果

- 点击任意 `Button` 按钮，播放一次 `button-dry.mp3`；
- 点击没有 Button 组件、但通过 `IPointerClickHandler`（如 `ShowObjectOnClick`、`UIHoverHide`、`UIHoverShow`、`ButtonHideShow`）响应点击的图片，同样播放；
- 音效自动受「总音量」和「音效开关」控制（`DataSystem` 中的设置）；
- 同一物体一次点击只响一声，即使它上面挂了多个点击脚本。

## 二、涉及文件

| 文件 | 作用 |
| --- | --- |
| `Assets/Project/Audio/button-dry.mp3` | 点击音效素材 |
| `Assets/Project/Resources/AudioLibrary.asset` | 音效库，点击音效的 ID 为 `ui_click` |
| `Scripts/Audio/GameAudio.cs` | 全局音频播放器（自动创建，切场景不销毁） |
| `Scripts/Audio/UiClickSound.cs` | 点击发声组件，负责实际播放并防止双响 |
| `Scripts/Audio/UiClickSoundInstaller.cs` | 自动扫描并给可点击物体补挂 `UiClickSound` |

## 三、工作原理（不用手动操作）

1. 游戏启动后，`UiClickSoundInstaller` 自动扫描当前场景；每次切换场景后再次扫描。
2. 扫描范围包含场景里**未激活**的物体，以及所有子层级。
3. 凡是带有 `Button` 组件或任意 `IPointerClickHandler` 组件的物体，如果还没有 `UiClickSound`，就自动补挂一个（同一物体不会重复挂）。
4. 运行时动态生成的界面也已接入：
   - 画像砖记录窗口（`RecordWindowLauncher` 生成 `RecordUI` 后自动扫描）；
   - 选关进入关卡时生成的 `Level1` 预制体（`HideAndInstantiate` 生成后自动扫描）。

因此在编辑器里新建按钮或可点击图片，只要使用 `Button` 组件或实现 `IPointerClickHandler`，运行时就会自动有点击音效。

## 四、`UiClickSound` 的发声规则

- 物体上**有 Button**：监听 `Button.onClick` 发声，销毁时自动移除监听；
- 物体上**没有 Button**：通过 `IPointerClickHandler.OnPointerClick` 发声；
- 两种方式互斥，避免「Button + 点击脚本」或多个点击脚本同时存在时一次点击响多声。

## 五、常见需求

### 1. 让某个按钮使用别的音效

在该物体的 `UiClickSound` 组件（运行时自动出现，也可手动预先添加）上，把 `Sound Id` 改为音频库中其他音效的 ID 即可。留空时使用默认 ID `ui_click`。

### 2. 某个可点击物体不想要点击音效

在该物体上手动添加 `UiClickSound` 组件并禁用它（取消组件左上角的勾选）。扫描器发现已存在该组件就不会再补挂。

### 3. 更换全局点击音效

两种方式任选：

- 直接替换 `Assets/Project/Audio/button-dry.mp3` 文件；
- 或在 `AudioLibrary.asset` 的 Sound Effects 中，把 `ui_click` 条目的 Clip 换成其他音频。

### 4. 通过代码播放点击音效

```csharp
GameAudio.Instance.PlaySound("ui_click");
```

## 六、验证与排查

1. 运行游戏，点击各处按钮，Console 应出现：
   `[GameAudio] Playing SFX: ID='ui_click', Clip='button-dry' ...`
2. 若显示 `Skipped SFX ... not found in AudioLibrary`：检查 `AudioLibrary.asset` 中是否存在 ID 为 `ui_click` 且已绑定 Clip 的条目。
3. 若显示 `sound effects disabled in settings`：音效被设置开关关闭，属正常现象。
4. 有播放日志但听不到声音：Unity 无法检测系统静音，请检查系统/播放器音量。
5. 音效最多同时播放 8 路，超出时当次点击会被跳过（Console 会有提示）。

## 七、角色脚步声（走路 / 跑步）

角色移动时按脚部落地节奏循环播放 `Assets/Project/Audio/雪怪在冰面上移动的拟音.mp3`，站定（Idle）时不响，同样受总音量与音效开关控制。

### 1. 配置链路

| 位置 | 内容 |
| --- | --- |
| `AudioLibrary.asset` | 音效 ID 为 `footstep`（原 ID `1` 已改名，全项目无引用，安全） |
| `Level1.prefab` 的「玩家」物体 | 挂有 `AudioCueTrigger`，`Sound Id = footstep` |
| `Art/Sprites/Character/走路/Walk.anim` | 每个循环 2 个动画事件（时间 0、0.5 秒），Function 为 `Play` |
| `Art/Player2/Run.anim` | 每个循环 2 个动画事件（时间 0、约 0.142 秒），Function 为 `Play` |

动画事件调用同物体上 `AudioCueTrigger.Play()`，再由它转调 `GameAudio.PlaySound("footstep")`，不需要写新脚本。

### 2. 为什么事件加在这两个动画上

「玩家」的 Animator（`Player2.controller`）中：`Idle → Walk → Run`，走路播 `Walk.anim`、按住跑步播 `Run.anim`（跑步片长约 0.28 秒，脚步自然比走路的约 1 秒更密）。`Sword_Walk` / `Sword_Run` 状态目前没有任何过渡连接，不会播放，故未配置。

> 注意：`Assets/Project/Animations/Run.anim` 是预制体中**默认隐藏的旧 Player 物体**（`m_IsActive: 0`）使用的片段，当前游戏里不会播放，因此没有加事件。

### 3. 常见需求

- **调整脚步快慢 / 对齐落地帧**：在 Animation 窗口打开对应片段，拖动事件标记即可；每循环 2 个事件是通用起步值。
- **换脚步声音效**：把 `AudioLibrary.asset` 中 `footstep` 条目的 Clip 换掉，或换素材后修改绑定。
- **跑步想用不同音效**：复制一个 `AudioCueTrigger` 用法不可行（同物体只能有一个），可改为让动画事件调用带参方法——把事件的 String 参数填另一个 ID（`AudioCueTrigger` 提供了 `Play(string id)` 重载），走路事件留空走默认、跑步事件填例如 `footstep_run`，并在音频库新增同名条目。
- **新增其他动画的音效**（攻击、跳跃等）：确认 `AudioCueTrigger` 在该角色物体上即可复用，在目标动画片段加 Function 为 `Play`（或 `Play` + 字符串参数）的事件。

### 4. 验证

1. 进入 Level1，用方向键走动，Console 应循环出现：
   `[GameAudio] Playing SFX: ID='footstep', Clip='雪怪在冰面上移动的拟音' ...`
2. 松开方向键回到 Idle 后日志停止；
3. 关闭音效开关后移动应静音（日志显示 skipped）。
