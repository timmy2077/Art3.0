## 本关流程

1. 视频结束后先进入饭店外场：地面和边界沿用 Level1，只显示饭店、庖长、玩家。靠近饭店入口按 E（手机点击“交互”）进入原有室内。内外场共用同一个玩家和庖长，外场可先与庖长交谈，进入后庖长位于原室内位置。
2. 靠近庖长，按 E 或手机“交互”打开对话。首次有“我来帮忙整理备餐”和“魏晋的宴席有哪些习俗”两个分支。
3. 科普线播完直接关闭，不再追加第二组选项；重新交谈可接任务。任务线播完正式接取第二关任务。
4. 在庖厨作坊和传菜廊道找回陶耳杯、食盘、烤肉炉。各拾取一次，集齐完成目标 1。
5. 回到庖长身边交谈，了解堵塞情况，再去灶台清理三处杂物，完成目标 2。
6. 再与庖长交谈，接取摆席安排。到主宴厅堂的宴席交互点打开器物配对。
7. 先选器物，再选对应位置：陶耳杯到置酒案、食盘到食案、烤肉炉到炉台。错误配对会提示，不推进进度。三件归位完成目标 3。
8. 回到庖长处交谈，取得缺失的画像砖碎片。此时只解锁拼图，不判定拼图已完成。
9. 打开右上角拼图，交换两片的位置，完成《庖厨图》修复。立即解锁 `paochu` 收藏和第三关。
10. 通关页面展示本关 Reward Brick Ids 对应砖图。可返回选关，也可回主页画像砖录查看成果。

按后续确认已移除宴饮宾客实例，室内只保留庖长和共用玩家；`Guest.asset` 资料保留，暂不挂载。庖长对话原文及各阶段内容分别保存在独立 SO 中，并接入已有的已读对话记录。人物志第二份档案为庖长。

## 饭店内外场配置（2026-10-22）

只修改第二关预制体，未修改 `Level1.prefab` 或 `Level1.unity`。`Level2.unity` 和 Select 视频入口继续引用同一份 Level2，不额外加载第一关任务。现有室内 `CookingEnvironment` 的地面、三处区域、案几和道具布局保持原样，原宾客对象移除。

- `RestaurantExterior/Ground`：从第一关原样复制的地面。
- `RestaurantExterior/饭店`：外场饭店图片；`饭店入口` 为靠近后交互的位置，`饭店名称锚点` 控制头顶“饭店”的位置。
- `ExteriorBounds`：复制第一关的相机和物理边界，只在外场启用；原 `Confiner` 只在室内启用。
- `RestaurantMarkers`：外场／室内玩家出生点、庖长位置及室内出口。可在编辑器移动这些锚点来调整进入落点，不要新增第二个玩家或庖长。
- 根节点 `CookingRestaurant`：引用上述区域、门口、出生点、相机和 `CookingPuzzle`。

外场初始只显示饭店、庖长、玩家及地面；室内环境与碰撞边界关闭。按 E 进入后，关闭外场并启用原室内，共用玩家与庖长移动到室内出生点。靠近室内左下“出口”按 E 可返回外场，再次进入不会重建任务。门口带短暂按键间隔，对话、拼图或配对面板打开时不能切换。

头顶标签只显示“饭店”“庖长”等名称，按 E 的说明由顶部统一提示承担。庖长的 `Automatic Keyboard Interaction` 关闭，由 CookingPuzzle 统一处理 E，防止同一次按键同时开对话和进门。第一关 NPC 保持原有默认行为。

饭店内外状态以 `Quest.chapter2_cooking.Cooking.InRestaurant` 保存：旧存档没有该键时先进入外场，之后继续游戏恢复最后所在区域；任务、拾取和配对仍使用原存档键。每次进入恢复固定安全出生点，不保存逐帧玩家位置。

本次内外场验证已在编辑器通过：外场显示、饭店及庖长名称、距离与弹窗限制、共用人物、出门再进入、区域与任务进度恢复、完整食器／灶台／配对／拼图奖励、返回选关及第一关实例化回归；玩家原存档未改变。菜单 **尘封砖语 → 第二关 → 验证饭店进出与任务（不等待视频）** 使用 Select 的同一份 Level2 引用直接验证这些流程，不等待编辑器后台可能暂停的原生视频。视频脚本本次未改动，手机真机尚未验证。

## 副本清理与美术替换

Level2 已移除第一关专属的牛、牛栏、围栏碰撞、赶牛逻辑、耙子、农耕动作和遗落耕具提示。没有通过隐藏这些节点来保留赶牛机制；配置验证也会检查牛、围栏及相关组件残留。

`CookingEnvironment` 按庖厨作坊、传菜廊道、主宴厅堂组织，室内保留当前布景；饭店图片用于外场入口。人物临时复用第一关现有外观。杯、盘、炉、案几使用可替换的简化形状，仅作为交互与布局素材，不作为文物形制考证依据。

替换人物时，保留“庖长”节点上的 `NPCInteraction` 及其引用；替换玩家外观时保留移动、刚体、碰撞及任务组件。替换食器图片时，保留三个食器的 Transform 与 CookingPuzzle.Utensils 数组顺序：陶耳杯、食盘、烤肉炉。改动灶台或宴席位置时移动对应节点，交互距离会跟随节点位置。

`CookingPuzzle` 的 Chef、Restaurant、Utensils、Stove、Banquet、Stove Debris 均已配置；Guest 留空。不要把第二关的任务 SO 换回第一关，否则会混用任务进度。

## 视频和手机播放

视频通过序列化的 VideoClip 引用随项目打包，无电脑绝对路径、联网下载或 StreamingAssets 文件路径依赖。源文件不改动，导入设置为 H.264 转码，并配置 Android 和 iPhone 平台。

点击后先保留选关砖图并显示“正在准备入场画面…”，透明遮罩拦截重复操作。运行时先准备解码器与 RenderTexture，收到首帧后再等待一轮渲染，才显示视频及黑色留边，避免准备阶段闪黑。视频使用独立全屏 Canvas，按比例适配屏幕；使用 DSP 音频时钟，不依赖 timeScale，音轨使用 Direct 输出。加载超时或播放停滞会出现“重试播放 / 返回选关”，不会直接生成关卡或把选关界面永久锁住。

手机切到后台时暂停；回前台重新准备并从头播放这段短视频。退出视频时清理解码器、音频与 RenderTexture，避免反复进入积累资源。手机横屏会显示方向键和交互按钮，电脑沿用 WASD/方向键、E 和鼠标。

换视频时，在 Select 的“第二关视频入场”组件中替换 Clip。建议继续使用 H.264 MP4、常见横屏尺寸和兼容的音轨，避免使用 HEVC 等设备支持差异较大的编码。保留 Prepare Timeout 和 Stall Timeout 的超时保护。

手机端稳定性仍需要真机验证；编辑器播放成功不能代替不同 Android/iOS 设备的解码、后台恢复与音频测试。本次不包含手机安装包发布。

Unity 编辑器后台运行时可能把原生视频停在首帧，测试入场时请保持该项目窗口和 Game 视图可见。代码在编辑器失焦且解码器暂停时不累计停滞超时；手机端仍使用应用暂停/恢复处理。当前指定视频约 1.88 秒，内容本身包含农耕砖画，按已确认的素材原样使用；Level2 玩法中没有牛或围栏。

## 保存与恢复

第二关使用 `Quest.chapter2_cooking` 命名空间，分别保存食器拾取、炉口清理次数、摆放位置、庖长阶段交谈与修砖状态。领取缺片前写入未解拼图标记，防止重新进入后误判为拼图已完成。

## 检查方法

正常验收请从 Select 开始：完成第一关解锁第二砖后，点击第二砖。不要通过隐藏 Locked 节点来假装解锁。仅调试本关玩法时，可直接运行 Level2 场景；该路径不经过入场视频。

自动验证在编辑器退出运行模式且已打开场景没有未保存修改时执行。向 `Artifacts/Level2/command.txt` 写入 `test`，编辑器会复制临时 Select 验证场景，跑视频、任务、配对、拼图与返回流程，然后恢复原场景。验证期间阻止 SaveManager 写盘，使用独立临时任务标识，玩家存档不会被测试覆盖。

结果和截图位于 `Artifacts/Level2`。`validation.txt` 是静态配置检查，`runtime-validation.txt` 与 `runtime-result.txt` 是运行流程检查。遇到错误时查看 `runtime-error.txt`。一次修复后应以最新一轮文件时间和结果为准。

2026-10-21 已在 Unity 2022.3.62f1 Windows 编辑器跑通真实 Select 入口：第二砖锁定检查、视频缺失与返回、H.264 首帧和连续播放、模拟应用暂停恢复、完整庖厨任务、错误配对拦截、中途进度恢复、领取缺片后仍未解拼图、修砖奖励与第三关解锁、返回选关和第一关实例化回归。另验证触屏方向按下/松开、交互按钮生成、配对弹窗遮挡触屏按钮。验证未覆盖玩家存档文件，未在手机真机上运行。

构建菜单“尘封砖语 / 第二关 / 构建庖厨关卡”属于原始重建工具，会覆盖布景、SO 文案和入口设置。检测到饭店内外场后会拒绝重建，保护后续手工配置。日常直接编辑 Level2 预制体，只使用“验证配置”或“验证饭店内外场配置”。首次内外场转换记录及原室内布局校验位于 `Artifacts/Level2Restaurant/`，其中保存转换前的 Level2 副本；不要把此副本重新导入 Assets，以免产生重复引用。

### 饭店碰撞与进门（2026-10-22）

饭店节点添加非 Trigger 的 BoxCollider2D，阻挡玩家穿过建筑。CookingRestaurant 的 Building Collider 引用该碰撞体，外场交互按玩家到建筑碰撞体最近点的距离判断；靠近建筑按 E 或手机「交互」即可进入。Interaction Distance 可调整距离。入口节点随饭店移动，出口仍按出口锚点判断。取消额外生成的「返回选关」，使用选关场景已有的「返回」。

### 饭店碰撞、宾客与返回更新

饭店 BoxCollider2D 只覆盖下方建筑实体（图片宽度的 88%、高度的 28%），屋顶及留白允许与人物画面重叠。可在饭店节点编辑碰撞体。宾客位于室内 CookingEnvironment 下，沿用 Guest 对话数据，外场隐藏。

左上角原返回按钮在关卡运行时销毁关卡副本、恢复当前选关页，不发放通关奖励、不跳 Index；在选关页再次按返回仍回主页。独立运行关卡且无选关界面时加载 Select。

### 入场与庖厨修正

每次新加载关卡先到饭店外，任务进度保留，不再因上次退出时位于室内而直接出现在室内。取消入场视频准备期间的文字提示，失败时仍提供重试提示。返回按钮使用独立 Canvas 排序 250，高于关卡标签。室内恢复 Level1 原「切菜」庖厨的外观与动画，移除宴饮宾客，使用 Cook.asset 对话数据。
