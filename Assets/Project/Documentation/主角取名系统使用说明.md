# 主角取名系统使用说明

## 当前效果

取名界面位于 `Index` 场景。点击左上角的 `playerWindow` 打开 `nameWindow`；输入名字并点击确认后，左上角的 `playerName` 立即更新。名字通过 `DataSystem` 保存，重新进入场景或重新启动游戏后仍会显示。

`nameWindow` 是场景中预先搭好的对象，平时隐藏，打开时复用；系统不会反复克隆预制体。当前不会在第一次进入 `Index` 时自动弹出取名界面，需要玩家点击 `playerWindow`。

## 场景对象与脚本

| 对象 | 用途 |
| --- | --- |
| `Canvas/UIMainview/playerWindow/imgbg` | 可点击的玩家信息区域；其中有 `Button` |
| `playerName` | 左上角显示当前名字的普通 `Text` |
| `Canvas/UIMainview/nameWindow` | 取名窗口，初始隐藏 |
| `NameInput` | Unity UI 的普通 `InputField`，不是 TMP |
| `confirmButton` | 确认并保存名字 |
| `errorText` | 输入不合法时显示提示，平时隐藏 |

`PlayerNameWindow` 脚本挂在 `UIMainview` 上。它的 `Player Button`、`Name Window`、`Name Input`、`Confirm Button`、`Player Name Text`、`Error Text` 已在 `Index` 场景中连接。按钮事件由脚本在运行时绑定，不需要再手动添加 `On Click()` 事件。

## 玩家操作流程

1. 进入 `Index`，左上角先显示默认名字 `Player`，或者此前保存的名字。
2. 点击 `playerWindow`，打开 `nameWindow`。第一次取名时输入框为空；已有保存名字时，输入框预填旧名字。
3. 输入新名字并点击 `confirmButton`。
4. 合法名字会更新 `playerName`、保存数据并关闭窗口。再次点击 `playerWindow` 可以改名。

输入前后的空格会被去掉。空名字提示“请输入名字”；名字中含空格、标点、符号或表情等特殊字符时提示“名字不能包含特殊字符”。中文、英文字母和数字可以使用。例如 `张三`、`Alice2` 合法，`张@三`、`Alice Smith` 不合法。输入错误时窗口保持打开，原输入保留，便于修改。

## 错误提示时间

选中 `Index` 场景的 `UIMainview`，在 Inspector 的 `Player Name Window (Script)` 中修改 `Error Duration`。默认值为 **2 秒**。连续输入错误时，提示计时会重新开始；关闭后再打开窗口时，旧提示会清除。计时使用真实时间，不受游戏暂停或 `Time.timeScale` 影响。

## 名字如何保存

`PlayerNameWindow` 调用 `DataSystem.SavePlayerName()`；`DataSystem` 使用 `PlayerPrefs` 的 `PlayerName` 键保存，并在运行时跨场景保留。`HasSavedPlayerName()` 用于区分“还没取过名”和“玩家真的取名为 Player”，不会仅靠显示文字判断。

`DataSystem.enablePersistence` 默认开启。若将其关闭，名字在当前运行期间仍可读取，但结束运行后不会保留。调用 `DataSystem.ClearAllData()` 会清除名字；重新进入 `Index` 后，左上角会显示默认名 `Player`。

## 左上角背景随名字变宽

当前 `playerWindow/imgbg` 使用 `Horizontal Layout Group`，并通过 `Content Size Fitter > Horizontal Fit = Preferred Size` 按 `playerName` 的文字宽度调整背景。背景左侧 Padding 为 `115`、右侧为 `50`，为头像和文字留出空间。若要调节左右留白，在 `imgbg` 的 `Horizontal Layout Group > Padding` 中修改；不要再把 `imgbg` 的左右锚点设为拉伸，否则会重新被父对象固定宽度控制。

**当前 `NameInput > Character Limit` 为 `0`，表示不限字数。** 如果希望最多六个字符，可在 Inspector 把它设为 `6`。目前脚本只检查空名字和特殊字符，没有额外的长度校验；很长的名字仍可能把背景撑出屏幕。

## 测试与排查

1. 在 `Index` 场景进入 Play 模式，点击左上角玩家信息，输入 `张三` 并确认；检查左上角是否立即变为 `张三`。
2. 再打开窗口，确认输入框预填 `张三`；改成 `张@三` 并确认，检查错误提示是否约 2 秒后消失，名字是否仍为 `张三`。
3. 停止并重新进入 Play 模式，检查 `张三` 是否仍显示。

若点击无反应，先检查 `UIMainview` 上 `Player Name Window (Script)` 的六个对象引用以及场景中 `EventSystem` 是否存在。若关闭游戏后名字丢失，检查 `DataSystem.enablePersistence` 是否开启。
