# 测试工具：关卡解锁

在 Unity 编辑器中运行任意游戏场景，屏幕顶部会出现 **测试工具 / F8** 按钮。点击按钮或按 **F8** 打开，点击 **关闭**、按 **Esc** 或再次按 **F8** 关闭。

## 解锁方式

- 每关右侧的 **解锁**：只解锁这一关。
- **解锁全部关卡**：解锁现有五关的入口。
- 已解锁关卡显示“已解锁”，不能重复点击。
- 选关场景内的锁定石砖会立即刷新，不需要重进场景。

解锁写入当前存档，重新运行游戏后仍保留；写入失败会在面板内提示。面板不会完成关卡任务，也不会发放砖画收藏。第三至第五关能否游玩，取决于这些关卡实际配置的完成情况。

## 手机测试与正式发布

手机测试打包时，在 **File → Build Settings** 勾选 **Development Build**，面板会自动出现，使用屏幕按钮操作即可。取消该选项的正式包不会自动创建此工具，手动放入预制体也会被移除。

工具跨场景保留，无需在各个场景中单独挂载。序章和第二关入场视频期间隐藏入口，避免影响入场流程。打开面板时会遮挡下层界面，并阻止角色移动、对话推进等输入；关闭后保留原来的输入锁定状态。

## 资源与维护

- 预制体：`Assets/Project/Resources/DebugUnlockPanel.prefab`，保存中文字体引用。
- 界面与行为：`Assets/Project/Scripts/UI/DebugUnlockPanel.cs`，运行时生成 UI。
- 字体：`Assets/Project/Fonts/SettingsYaHei.ttf`。
- 重新生成预制体：Unity 菜单 **Tools → 尘封砖语 → 生成关卡测试工具**。
- 编辑器验证：**Tools → 尘封砖语 → 验证关卡测试工具**。验证使用临时选关场景，阻止存档写盘，结束后恢复原场景；运行前请保存已打开的场景。

关卡解锁调用现有 `DataSystem.UnlockLevel()`，随后刷新场景内所有 `LevelUnlock`（包括暂未显示的选关页面）。不调用通关、任务或收藏奖励事件。
