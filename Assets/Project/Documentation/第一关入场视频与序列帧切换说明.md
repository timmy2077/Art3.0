# 第一关入场：视频与序列帧切换

第一关现在默认使用 `Assets/Project/Video/扬场图入场.mp4`，与第二关使用同一段视频、同一套播放逻辑。第一关视频结束后实例化 **Level1**，第二关仍实例化 **Level2**。

准备视频时保留选关砖图，首帧就绪后再显示视频。重复点击不会重复进入；播放失败可以重试或返回选关。视频使用 VideoClip 资源引用，手机打包不依赖电脑绝对路径。

## 如何把第一关视频换回序列帧

1. **退出 Play 运行模式**，打开 `Assets/Project/Scenes/Select.unity`。
2. 在 Hierarchy 搜索并选中 **耕种图动画**。这个对象默认是灰色、未激活的，保持该状态即可。
3. 在 Inspector 找到 **Level Entrance Selector (Script)** 组件。
4. 将 **Mode** 从 **视频** 改为 **序列帧**。
5. 按 **Ctrl + S** 保存 Select 场景。运行后点击第一块砖，会播放原来的序列帧动画；末帧事件生成第一关。

改回视频时，重复以上步骤，将 **Mode** 选为 **视频** 并保存。不要在运行时改完就退出：Play 模式中的 Inspector 修改不会保存在场景里。

只改 Mode 即可。**不要删除或手动切换下列组件的勾选**：入口激活时，Selector 会自动启用对应一套组件。不要为“恢复序列帧”去运行第二关的重建菜单。

## 为什么能随时换回去

同一个“耕种图动画”对象保留了以下引用：

| 组件／字段 | 用途 |
| --- | --- |
| Level Entrance Selector → Video Entrance | 第一关视频控制组件 |
| Level Entrance Selector → Sequence Animator | 原 Animator，控制器仍是 `One.controller` |
| Level Entrance Selector → Sequence Image | 原序列帧 Image |
| Level Entrance Selector → Sequence Completion | 原 HideAndInstantiate，保留选关和 Level1 引用 |
| Level Video Entrance → Clip | 当前使用的入场视频 |
| Level Video Entrance → Level Prefab | `Assets/Project/Prefabs/Level1.prefab` |
| Level Video Entrance → Selection UI | 原来要隐藏的选关界面 |

原序列帧资源位于 `Assets/Project/Art/Bricks/Animations/耕种图关卡/`，没有删除。`Show.anim` 的 **2 秒处**仍保留 `OnAnimationFrame` 动画事件，负责在序列帧播放结束时生成第一关。

视频模式下 Animator、序列帧 Image 和 HideAndInstantiate 会停用；原动画回调即使被误触发，也不会再生成第二份关卡。序列帧模式下视频组件停用，原组件会恢复，动画每次从头播放。

## 更换成另一个视频

1. 退出运行，将新视频放入 Assets 文件夹并等待 Unity 导入。
2. 选中 **耕种图动画**，在 **Level Video Entrance → Clip** 拖入新 VideoClip，Mode 保持 **视频**。
3. 保留 **Level Prefab = Level1** 和原 **Selection UI**，保存场景。
4. 视频建议使用 H.264 和常见兼容音轨，并检查 Android / iPhone 的导入设置。从 Select 实际点击第一砖测试，再用目标手机验证解码和后台恢复。

不要直接给该入口另加一个自动播放的 VideoPlayer：解码器和 RenderTexture 由脚本创建、释放，手动添加会造成两套播放器。

## 验证

运行时从 Select 点击第一砖，应先显示准备提示，再播放视频，最后只生成一份 Level1。将 Mode 改成序列帧后，应正常播放原动画并生成 Level1，第二砖入口不受影响。

编辑器菜单 **尘封砖语 → 第一关 → 验证视频与序列帧入口** 会在临时 Select 场景验证两种方式，结束后恢复原场景。验证期间阻止存档写盘，结果位于 `Artifacts/Level1Entrance/`。运行前保存打开的场景，播放视频时保持 Unity 的 Game 视图在前台。手机稳定性仍需真机验证。

菜单 **尘封砖语 → 第一关 → 配置可切换视频入口** 用于重新建立默认视频引用，会将 Mode 和 Clip 恢复为本文的初始设置；日常切换只改 Mode，不必再次执行配置菜单。
