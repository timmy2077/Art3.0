# 美术资源目录

统一入口：`Assets/Project/Art`。

| 文件夹 | 放什么 |
| --- | --- |
| `Characters` | 玩家、NPC、人物动作动画 |
| `Environments` | 地图背景、建筑 |
| `Props` | 动物、工具、围栏、拼图道具 |
| `Bricks` | 画像砖静态图片、砖块贴图、各关卡砖画动画 |
| `Cinematics` | Logo、标题片头动画 |
| `UI` | 主菜单、设置、公共界面按钮 |

## 常用位置

- `Characters/Actions`：原 `Sprites/Character`，按动作分组，保留动作名称。
- `Characters/Player/Variant01`：原 `Sprites/Player` 的帧图、动画及控制器。
- `Characters/Player/Variant02`：原 `Player2`，保留 `Player2.controller` 文件名。
- `Characters/Player/Portraits`：玩家静态人物图。
- `Characters/NPCs`：白身、dagan 等 NPC 静态图；骑马驿使帧图位于 `Courier/Frames`。
- `Environments/Backgrounds`：地图、背景和地面纹理；`Buildings`：茅草屋、饭店等建筑图片。
- `Props/Animals`：白牛、黑牛；`Tools`：耙子；`FencesAndPuzzlePieces`：围栏和拼图道具。
- `Bricks/Illustrations`：砖画静帧；`Textures`：空砖块；`Animations`：按砖画/关卡分组的序列帧和动画。
- `Cinematics/Logo`、`Cinematics/Title`：原 Logo 序列、`TitleSequence`。
- `UI/MainMenu`：主菜单背景、人物装饰和开始按钮；`Settings`：设置界面；`Common`：通用箭头。

## 后续放置规则

1. 新资源按用途进入上面的分类，不再把地图、按钮、角色一起放进“画像砖”。
2. 同一套动画的帧图、动画片段和控制器保留在同一组目录，避免同名 `Run.anim` 等难以区分。
3. 移动、重命名优先在 Unity Project 面板里完成；在文件系统操作时，资源和对应 `.meta` 必须一起移动。
4. 不要因名称相似就删除素材。不同图片、不同导入设置和不同版本可能各有引用。
